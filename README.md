# Nexus Trading Desk
Responsive, local-first educational trading workspace.

## Features
- Paper-trading journal, P/L, win rate, average R and CSV export
- Technical-analysis checklist and TradingView launcher
- Risk-based position sizing calculator
- Hypothetical return-sequence simulator with equity curve and drawdown
- Links to Indian market information sources
- AI research prompt generator

## Run
Open `index.html` in a modern browser. No build tools or dependencies required.

## Publish with GitHub Pages
1. Create a new public repository named `nexus-trading-desk`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.

## Limitations
No live price/news feed, AI model, broker connection or order execution. Journal is saved in this browser's localStorage. Backtest uses manually supplied returns, not historical price data. Educational only; not investment advice.
